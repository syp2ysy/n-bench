# CSUR Patterns

For `target=csur`, use only official ACM Computing Surveys exemplars listed in `csur_official_exemplars.yml` or custom exemplars with ACM DL DOI verification.

CSUR-style moves:

- abstract: field importance -> fragmentation/gap -> organizing framework -> evidence artifacts -> agenda;
- introduction: field shift -> existing survey gap -> survey object -> contributions -> roadmap;
- foundations: definitions -> boundary -> running example or unifying object;
- taxonomy: define dimensions before papers;
- benchmark/evaluation: capability -> protocol -> metric -> baseline -> confounder;
- open problems: evidence gap -> why hard -> concrete research move.

CSUR imitation is a writing guide, not article content. Do not expose exemplar notes, DOI pools, or rhetoric-mining labels in `review.md`.
