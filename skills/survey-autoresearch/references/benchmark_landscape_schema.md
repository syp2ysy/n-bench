# Benchmark Landscape Schema

Use this reference for `outputs/benchmark_landscape.md`.

Required table:

```markdown
| Benchmark | Task family | Environment | Memory pressure | Required memory fields | Input / Output | Metrics | Baselines | Memory-specific ablations | Confounders | Best-suited method families | Representative papers |
```

The benchmark section in `review.md` must teach how to choose and interpret benchmarks. Do not only name benchmark papers. For each entry, state what memory ability is tested, what is confounded, and what extra ablation is needed.
